# 0010. グラフはライブラリを使わず SVG で描く

- ステータス: 採用
- 日付: 2026-10-09
- 関連: #8

## 背景

ダッシュボードに、所要時間の推移とリクエストのウォーターフォールを出す。種類は少ないが、見た目と操作性（ホバー・キーボード・表への切り替え）にはこだわりたい。

## 決定

- グラフは React コンポーネントで SVG を直接描く（`ElapsedChart`・`Waterfall`）
- 色は dataviz スキルの検証済みパレットを使う（カテゴリ 3 色。ライト / ダークそれぞれでバリデータを通したもの）
- 仕様: 線 2px、マーカーに 2px の縁取り、目盛り線は 1px の実線、二重軸は使わない、2 系列以上なら凡例、表ビューへの切り替え、ホバーとキーボードの両方で値を読める
- 状態の色（成功・売り切れなど）は系列の色と分け、必ずアイコン + ラベルと一緒に使う

## 理由

- 2 種類のグラフのためにライブラリを入れると、見た目の調整とバンドルサイズのコストの方が大きい
- アクセシビリティの振る舞いを自分で決められる

## 検討した他の案

- Recharts / Chart.js: 手早いが、細部の調整で結局手を入れることになる

## 影響

- 新しいグラフを足すときも同じ仕様に従う（`docs/development/coding-guidelines.md`）
- パレットを変えるときは dataviz のバリデータを通す
