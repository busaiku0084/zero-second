# 0019. 購入前チェックリストは、予約を作るときにテンプレートから写す

- ステータス: 採用
- 日付: 2026-10-10
- 関連: #13

## 背景

発売前に確かめておくこと（ログインできるか、会員情報、支払い方法、枚数・同行者など）を予約ごとにチェックしたい。サイトごとに少しずつ違い、予約ごとに足したいこともある。

## 決定

- テンプレートは `packages/shared/src/checklist.ts` の `checklistTemplate(site, mode)` に置く（サイト名と購入のしかたで少し変える）
- 予約を作るときに、テンプレートの項目を `checklist_items` に**写す**。以降はその予約だけの項目として、チェック・追加・削除できる
- テンプレートを後から変えても、作成済みの予約の項目は変わらない。「テンプレートの項目を戻す」で、今のテンプレートのうち無いものだけを足せる
- すべての項目が済んだ予約は、一覧に「準備完了」と出す（項目がなければ出さない）

## 理由

- 予約ごとに足したり消したりでき、チェックの状態もその項目に持てる
- テンプレートはコードと一緒に管理でき、サイトを足すとき（docs/development/adding-a-site.md）に項目も見直せる

## 検討した他の案

- テンプレートを参照し、チェックの状態だけを持つ: テンプレートを変えると、チェック済みの項目がずれたり消えたりする
- テンプレートを DB に持ち、画面で編集できるようにする: 今は使う人が少なく、画面と権限の設計に見合わない

## 影響

- この変更より前に作った予約には項目がない。予約詳細の「テンプレートの項目を戻す」で入れる
