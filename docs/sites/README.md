# サイト別の対応状況

新しいサイトに着手する前に `.claude/skills/new-site-adapter` の手順で利用規約を確認し、ここに記録する。

| サイト | 対応 | 規約の確認日 | 規約の改定日 | 判断の根拠 |
|---|---|---|---|---|
| TicketDive | 自動購入は対応しない | 2026-10-08 | 2026-07-06 | 購入者利用規約 第10条で「自動入力を行うソフトウェアやいわゆるBOT等の技術的手段」による利用と、リバースエンジニアリング・構造の解析を禁止。違反時は第11条によりチケット無効化・払い戻しなしの可能性 |
| LivePocket | 自動購入は対応しない | 2026-10-09 | 2026-06-04 | 利用規約 第13条第25号で「ボットなどの自動化手段を用いて本サービスを利用する行為」を禁止。違反時は第14条によりチケット無効化・払い戻しなしの可能性 |

対応しないサイトでも、購入補助（リマインド・カウントダウン・チェックリスト・手動購入の記録）は使える。
`packages/shared/src/sites.ts` の `automation` はこの表と必ず一致させる。
